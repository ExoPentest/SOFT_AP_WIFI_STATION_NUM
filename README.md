# SOFT_AP_WIFI_STATION_NUM
**Soft_Ap_Wifi_Station_Num** is a code for ESP32 DEVKIT-1 That validates the number of connected devices within the Soft Access Point. This is a really small Repo for the code that might help in remote tasks.

- **Requirements**
- Just an Arduino IDE.
- Mostly ESP32 Micro-Controllers with Built in WiFi. DEVKIT V1 WAS USED HERE
